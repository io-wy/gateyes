# Gateyes 本地使用方法

> 目标：从源码把 Gateyes gateway 跑起来，并用真实请求验证限流、路由、gRPC 插件、WASM 插件、协议转换。

## 1. 环境准备

### 1.1 必需依赖

- **Go 1.23+**
- **TinyGo 0.31+**（编译 WASM 插件需要）
  ```bash
  brew install tinygo
  tinygo version
  ```
- **PostgreSQL**（gateway 启动会 auto-migrate）
- **Redis**（限流、缓存、熔断器状态共享）

### 1.2 克隆与初始化

```bash
git clone <repo>
cd gateyes
cp .env.example .env
cp configs/config.example.yaml configs/config.yaml
```

编辑 `.env`：

```bash
# 数据库
GATEYES_DATABASE_DSN="host=localhost port=5432 user=gateyes password=your_password dbname=gateyes sslmode=disable"

# 上游 provider key（以 codexapis 为例）
CODEXAPIS_API_KEY=sk-your-key

# bootstrap key
GATEYES_DEMO_SECRET=demo-secret-001
GATEYES_ADMIN_BOOTSTRAP_SECRET=local-admin-secret
```

编辑 `configs/config.yaml`：

```yaml
server:
  listenAddr: ":8028"

database:
  driver: postgres
  dsn: "${GATEYES_DATABASE_DSN}"
  autoMigrate: true

redis:
  addr: "localhost:6379"

providers:
  - name: codexapis
    type: openai
    vendor: openai
    endpoint: chat
    baseURL: https://www.codexapis.com/v1
    apiKey: ${CODEXAPIS_API_KEY}
    model: gpt-5.4
    weight: 100
    enabled: true

apiKeys:
  - key: demo-key-001
    secret: ${GATEYES_DEMO_SECRET}
    quota: -1
    qps: 1000

admin:
  defaultTenant: default
  bootstrapKey: admin-key-001
  bootstrapSecret: ${GATEYES_ADMIN_BOOTSTRAP_SECRET}
```

## 2. 启动 Gateway

```bash
go run ./cmd/gateway -config configs/config.yaml
```

成功日志大致如下：

```json
{"level":"INFO","msg":"gateway listening","addr":":8028"}
{"level":"INFO","msg":"pprof listening","addr":":6060"}
```

## 4. gRPC 插件使用

### 4.1 插件示例（reverse router）

```go
package main

import (
	"context"
	"fmt"
	"net"
	"sort"

	"google.golang.org/grpc"
	"google.golang.org/grpc/health"
	healthpb "google.golang.org/grpc/health/grpc_health_v1"

	pluginv1 "github.com/gateyes/gateway/pkg/plugin/v1"
)

type reverseRouterPlugin struct {
	pluginv1.UnimplementedRouterPluginServer
}

func (s *reverseRouterPlugin) OrderCandidates(ctx context.Context, req *pluginv1.OrderCandidatesRequest) (*pluginv1.OrderCandidatesResponse, error) {
	names := make([]string, 0, len(req.Candidates))
	for _, c := range req.Candidates {
		names = append(names, c.Name)
	}
	sort.Sort(sort.Reverse(sort.StringSlice(names)))
	fmt.Printf("[GRPC_ROUTER_PLUGIN] ordered reverse: %v\n", names)
	return &pluginv1.OrderCandidatesResponse{OrderedNames: names}, nil
}

func main() {
	lis, err := net.Listen("tcp", ":50051")
	if err != nil {
		panic(err)
	}
	s := grpc.NewServer()
	pluginv1.RegisterRouterPluginServer(s, &reverseRouterPlugin{})

	hs := health.NewServer()
	hs.SetServingStatus("", healthpb.HealthCheckResponse_SERVING)
	healthpb.RegisterHealthServer(s, hs)

	fmt.Println("gRPC router plugin listening on :50051")
	if err := s.Serve(lis); err != nil {
		panic(err)
	}
}
```

### 4.2 启动插件

```bash
cd plugins/examples/grpc_router
go mod tidy
go run .
```

### 4.3 在 gateway 配置中接入

```yaml
grpcPlugins:
  - name: random-router
    type: router
    address: localhost:50051
    timeout: 100
```

启动顺序：**先启动 gRPC 插件，再启动 gateway**。gateway 日志里出现 `grpc plugin became healthy` 即表示连接成功。

### 4.4 验证路由生效

发送请求后查 trace：

```bash
curl -X GET http://localhost:8028/admin/responses/<response_id>/trace \
  -H "Authorization: Bearer admin-key-001:local-admin-secret"
```

关键字段：

```json
{
  "trace": {
    "router": {
      "strategy": "plugin:random-router"
    },
    "ordered_candidates": ["codexapis-responses", "codexapis-chat-alt", "codexapis"],
    "final_provider": "codexapis-responses"
  }
}
```

## 5. WASM 插件使用

### 5.1 编译环境

```bash
brew install tinygo
tinygo version   # >= 0.31
```

### 5.2 示例：响应改写插件

`plugins/examples/wasm_transform/main.go`：

```go
package main

import (
	"encoding/json"
	"github.com/gateyes/gateway/plugins/sdk/gateyes"
)

func transformResponse(payload []byte) []byte {
	var envelope map[string]json.RawMessage
	if err := json.Unmarshal(payload, &envelope); err != nil {
		return payload
	}
	respBytes, ok := envelope["response"]
	if !ok {
		return payload
	}

	var resp map[string]any
	if err := json.Unmarshal(respBytes, &resp); err != nil {
		return payload
	}
	outputs, ok := resp["output"].([]any)
	if !ok || len(outputs) == 0 {
		return payload
	}
	output, ok := outputs[0].(map[string]any)
	if !ok {
		return payload
	}
	contents, ok := output["content"].([]any)
	if !ok || len(contents) == 0 {
		return payload
	}
	content, ok := contents[0].(map[string]any)
	if !ok {
		return payload
	}
	text, ok := content["text"].(string)
	if !ok {
		return payload
	}
	content["text"] = "[WASM] " + text

	out, err := json.Marshal(resp)
	if err != nil {
		return payload
	}
	return out
}

//export evaluate_gateway
func evaluateGateway(inputPtr, inputLen, outputPtr, outputMaxLen int32) int32 {
	ev := gateyes.ReadGatewayEvent(inputPtr, inputLen)

	switch ev.Phase {
	case "post_upstream":
		transformed := transformResponse(ev.Payload)
		if len(transformed) == 0 {
			return gateyes.WriteGatewayCommand(outputPtr, gateyes.BlockGateway("transform_len=0"))
		}
		return gateyes.WriteGatewayCommand(outputPtr, gateyes.TransformGateway(transformed))
	default:
		return gateyes.WriteGatewayCommand(outputPtr, gateyes.AllowGateway())
	}
}

func main() {}
```

### 5.3 编译 WASM 插件

```bash
cd plugins/examples/wasm_transform
tinygo build -o wasm_transform.wasm -target=wasi -no-debug -opt=z .
```

### 5.4 在 gateway 配置中接入

```yaml
plugins:
  enabled: true
  directory: "./plugins"
  autoReload: true
  reloadIntervalSeconds: 30

wasmPlugins:
  - name: wasm-transform
    path: ./plugins/examples/wasm_transform/wasm_transform.wasm
    phases:
      - post_upstream
    timeoutMs: 50
    memoryPages: 2
```

启动 gateway 后，日志里出现：

```json
{"level":"INFO","msg":"loaded wasm plugin","component":"wasm_plugin_manager","name":"wasm-transform","phases":["post_upstream"]}
```

### 5.5 验证 WASM 生效

```bash
curl -X POST http://localhost:8028/v1/responses \
  -H "Authorization: Bearer demo-key-001:demo-secret-001" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.4","input":"say hello","max_tokens":5}'
```

返回的 `output_text.text` 前缀会带上 `[WASM]`：

```json
{
  "output": [{
    "content": [{
      "type": "output_text",
      "text": "[WASM] Hello!"
    }]
  }]
}
```

## 6. 限流验证

通过 Admin API 把某个 key 的 QPS 降到 2：

```bash
# 先拿到 key id
curl -X GET http://localhost:8028/admin/keys \
  -H "Authorization: Bearer admin-key-001:local-admin-secret"

# 修改 rate_limit_qps
curl -X PUT http://localhost:8028/admin/keys/<key-id> \
  -H "Authorization: Bearer admin-key-001:local-admin-secret" \
  -H "Content-Type: application/json" \
  -d '{"rate_limit_qps": 2}'
```

并发发 5 个请求，应看到部分 429：

```bash
for i in {1..5}; do
  curl -s -o /dev/null -w "%{http_code} " -X POST http://localhost:8028/v1/chat/completions \
    -H "Authorization: Bearer demo-key-001:demo-secret-001" \
    -H "Content-Type: application/json" \
    -d '{"model":"gpt-5.4","messages":[{"role":"user","content":"hi"}],"max_tokens":3}' &
done
wait
```

预期输出类似：

```text
429 429 200 200 429
```

## 7. 常见问题

### 7.1 端口被占用

```bash
lsof -ti:8028 | xargs kill -9
lsof -ti:6060 | xargs kill -9
```

### 7.2 gRPC 插件连不上

- 确认插件先启动、gateway 后启动
- 确认 `address` 和实际监听端口一致
- 确认注册了 `grpc_health_v1.RegisterHealthServer`

### 7.3 WASM 插件不生效

- 确认 `plugins.enabled: true`
- 确认 `wasmPlugins` 的 `phases` 包含请求实际经过的 phase
- 确认 `.wasm` 文件路径正确
- 确认导出了 `//export evaluate_gateway`

### 7.4 路由 trace 里有很多已删除的 provider

删除 provider 只会从 registry 移除，tenant 的 provider 列表不会自动清理。需要调：

```bash
curl -X POST http://localhost:8028/admin/tenants/default/providers \
  -H "Authorization: Bearer admin-key-001:local-admin-secret" \
  -H "Content-Type: application/json" \
  -d '{"providers":["codexapis","codexapis-chat-alt","codexapis-responses"]}'
```
